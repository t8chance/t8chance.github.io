Each row is one such post for a named storm in 2025–26, storms not used to set up this site, beside this site's chance for the same storm from the forecast that was available when the post went out. A row goes to whichever side leaned the right way when the other did not. On both sides 40–59% counts as a 50-50, which is MET WARN's own definition of 中等.
